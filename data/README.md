# 2026 category data

This dataset is scoped to January–December 2026. Category names come from workbook filenames, and TLDs come from workbook rows. `Coming` is represented as `null`; a null value means the source has not supplied that month, not zero registrations.

The source-file mapping is authoritative for the uploaded files. Categories whose workbooks were not machine-extracted in this publication remain empty and must be populated from their corresponding workbooks before the site is described as complete.
